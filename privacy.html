プライバシーポリシー

最終更新日：2026年9月12日

Channel Live Now（以下「本拡張機能」）は、ユーザーのプライバシーを尊重し、 GoogleおよびYouTubeから取得するユーザーデータを、 本拡張機能の提供に必要な範囲でのみ利用します。

1. 取得する情報

本拡張機能は、Google OAuth 2.0による認証を使用し、 YouTube Data APIを通じて以下の情報にアクセスします。

  • ユーザーのYouTubeアカウントに関連する情報
  • ユーザーが登録しているYouTubeチャンネルの情報
  • 登録チャンネルの配信状況など、本拡張機能の表示に必要なYouTube上の情報

本拡張機能では、YouTubeの読み取り専用権限 （youtube.readonly）のみを使用します。

本拡張機能が、GoogleやYouTubeのパスワードを取得することはありません。

2. 情報の利用目的

取得した情報は、以下の目的にのみ使用します。

  • ユーザーが登録しているYouTubeチャンネルを取得するため
  • 登録チャンネルのうち、現在ライブ配信を行っているチャンネルを確認・表示するため
  • Googleアカウントとの接続状態を維持するため
  • 本拡張機能の機能を提供するため

取得したGoogleおよびYouTubeのユーザーデータを、 広告、マーケティング、ユーザー分析その他これらと無関係な目的には使用しません。

3. 認証情報およびデータの保存

本拡張機能では、Googleアカウントとの接続を維持するため、 Google OAuth 2.0により発行された短時間有効なアクセストークンと、 同じGoogleアカウントを再選択するために使用するアカウント選択番号を、 ユーザーが使用するブラウザの拡張機能専用ローカルストレージに保存します。

アクセストークンは、 YouTube Data APIへ認証済みリクエストを送信する目的にのみ使用します。 Google OAuthおよびYouTube Data APIとの認証・通信を除き、 アクセストークンを開発者が管理するサーバーやその他の第三者へ 送信または保存することはありません。

アクセストークンの有効期限が切れた場合は、 ユーザーのブラウザにGoogleへのログイン状態が残っている場合に限り、 Google OAuthを通じて新しいアクセストークンの取得を試みます。

本拡張機能は、更新トークン（Refresh Token）やClient Secretを保存しません。 また、GoogleやYouTubeのパスワードやCookieを、 本拡張機能が取得または保存することはありません。

YouTube Data APIから取得した情報についても、 本拡張機能の機能を提供するためにのみ使用し、 開発者が管理する外部サーバーへ収集・保存することはありません。

4. 第三者への提供

本拡張機能は、GoogleおよびYouTubeから取得したユーザーデータを、 第三者へ販売したり、本拡張機能の提供と無関係な目的で 提供・共有したりすることはありません。

ただし、本拡張機能の機能を提供するため、 Google OAuth 2.0およびYouTube Data APIとの認証・通信を行います。

5. Google API Services User Data Policyへの準拠

本拡張機能によるGoogle APIから取得した情報の利用は、 Google API Services User Data Policy（Limited Use要件を含む）に準拠します。

Googleから取得したユーザーデータは、 本プライバシーポリシーに記載された本拡張機能の機能を提供する目的にのみ使用します。

6. データの削除について

本拡張機能の「接続を解除」を実行した場合、 ブラウザ内に保存されているアクセストークンや アカウント選択番号などの認証情報を削除します。

また、「接続を解除」した際には、 Google側でも本拡張機能に対して発行されたアクセス権の無効化を試みます。

ユーザーは、Googleアカウントの設定から 本拡張機能へのアクセス権を取り消すこともできます。

本拡張機能をブラウザから削除した場合も、 本拡張機能がブラウザ内に保存している情報は削除されます。

7. プライバシーポリシーの変更

本拡張機能の機能変更やGoogle APIの利用方法の変更などに伴い、 本プライバシーポリシーを変更する場合があります。

Googleユーザーデータの取得、利用、保存または共有方法に変更が生じた場合は、 本ページの内容を更新します。

8. お問い合わせ

本プライバシーポリシーまたは本拡張機能に関するお問い合わせは、 本拡張機能の開発者までご連絡ください。
